PROYECTO DE BASE DE DATOS PARA UN SISTEMA DE DISEÑO Y 
GESTIÓN DE PEDIDOS DE MUEBLES PERSONALIZADOS 

1. introducción
El presente proyecto tiene como finalidad analizar los procesos y las necesidades de una ensambladora de muebles mediante una entrevista, con el propósito de recopilar información que permita diseñar una base de datos adecuada para la gestión y organización de sus operaciones.

La información obtenida permitirá identificar los principales procesos de la empresa, los datos que se manejan y las posibles dificultades en el control de sus actividades.

2. Objetivo de la entrevista

Recopilar información sobre el funcionamiento de la empresa, sus procesos administrativos y operativos, el manejo de inventarios, las compras, los proveedores, la producción y las ventas, para establecer los requerimientos necesarios para el diseño de una base de datos.

4. Resumen de la entrevista
Resumen de la entrevista

La entrevista tuvo como finalidad recopilar información sobre el funcionamiento de una mueblería dedicada a la fabricación de muebles a medida y a los servicios de ensamblaje e instalación. Se abordaron aspectos relacionados con el registro de clientes, la gestión de pedidos, la personalización de muebles, el control de materiales, los proveedores, los pagos y las entregas.

A partir de las respuestas obtenidas, se identificó la necesidad de contar con una base de datos que permita centralizar y organizar la información, registrar las características de los muebles solicitados, controlar el estado de cada pedido y realizar el seguimiento de los servicios de ensamblaje y entrega.

Como resultado, se determinaron las principales entidades para el diseño de la base de datos, entre ellas: CLIENTE, PEDIDO, MUEBLE, DETALLE_PEDIDO, EMPLEADO, ENSAMBLAJE, PAGO y ENTREGA. Estas entidades permitirán estructurar la información y facilitar su consulta y administración.

En conclusión, la implementación de una base de datos para la página web contribuiría a mejorar la organización de la mueblería, facilitar el seguimiento de los pedidos y optimizar la gestión de la información. Las respuestas utilizadas como ejemplo deberán validarse mediante entrevistas reales.
